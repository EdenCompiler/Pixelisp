# Running and modifying examples

Load `pixelisp/examples` from Quicklisp, or use the launcher from this checkout:

```sh
sbcl --script scripts/example.lisp --list
sbcl --script scripts/example.lisp sprite-lab
```

All interactive examples process events, update state, draw, and present on
the initializing thread. Escape or closing the window ends a run. All images
and sounds are generated by Lisp code; text uses the bundled DejaVu font.

| Name | Kind and controls | What to read |
| --- | --- | --- |
| `star-collector` | Game: arrows/WASD move, collect stars | `examples/examples.lisp`: sprites, transforms, masks, UTF-8 text, audio |
| `sprite-lab` | Arrows/WASD move; click to launch particles | `examples/sprite-lab.lisp`: GroupSingle, CLOS update, shared particle art, additive blending |
| `mask-lab` | Arrows/WASD move; pink pixels show overlap | `examples/mask-lab.lisp`: alpha masks, overlap masks/counts, offset painting and skipped pixels |
| `image-lab` | G grayscale, T threshold, C original color | `examples/image-lab.lisp`: cached transforms and Laplacian edge detection |
| `ui-lab` | B filters motion, G grabs mouse, K grabs keyboard, Escape exits | `examples/ui-lab.lisp`: event names, filtering, native grabs, cached status text and exceptional cleanup |
| `pixel-lab` | Hold Left/Right for tolerance, Space changes weights, T transposes, R resets | `examples/pixel-lab.lisp`: keyboard repeat, weighted matching, dependent views, format queries and vector batch blits |
| `pixels` | Export a generated gradient | `pixel-demo`: shared RGB views and X/Y/channel indexing |
| `effects` | Export a four-panel effects comparison | `effects-demo`: HSV colors, aspect fitting, RGB blends and premultiplied alpha |
| `palette` | Export named-color swatches with grayscale strips | `examples/api-recipes.lisp`: names, Color parsing, grayscale and text labels |
| `rounded-ui` | Export six UI styles | `examples/ui-lab.lisp`: Color arithmetic, I1I2I3, individual corner radii and inward borders |
| `pixel-match` | Export a source/edited color chart | `examples/pixel-lab.lisp`: weighted color replacement, native format metadata and owned preview copies |
| `memory-image` | Export an image decoded from embedded PNG bytes | `examples/system-recipes.lisp`: encoded octet decoding and a scoped temporary surface |
| `sound` | Play one generated chime | `sound-demo`: sample arrays, mixer initialization and cleanup |
| `sound-events` | Play two queued chimes and consume completion events | `examples/api-recipes.lisp`: channel end events and a two-second bounded pump |
| `mask-info` | Print an overlap coordinate and area | `mask-demo`: native-independent collision results after loading the toolkit |
| `display-info` | Print video driver, display count, modes and display details | `examples/system-recipes.lisp`: video capability queries without opening a window |

Interactive labs accept `--frames N` and `--fps N`; Star Collector keeps its
60 FPS cap. `--no-audio` disables sound in Star Collector or skips the sound
examples. A zero frame count initializes and cleans up without running a frame.

```sh
# A bounded lab using real SDL allocations with dummy device drivers.
SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy \
  sbcl --script scripts/example.lisp mask-lab --frames 3 --fps 120

# Image examples save into the current directory unless a path is supplied.
sbcl --script scripts/example.lisp effects --output /tmp/pixelisp-effects.png
sbcl --script scripts/example.lisp palette --output /tmp/pixelisp-palette.png
sbcl --script scripts/example.lisp rounded-ui --output /tmp/pixelisp-ui.png
sbcl --script scripts/example.lisp ui-lab
sbcl --script scripts/example.lisp pixel-lab
sbcl --script scripts/example.lisp pixel-match --output /tmp/pixelisp-pixel-match.png
sbcl --script scripts/example.lisp memory-image --output /tmp/pixelisp-memory-image.png
sbcl --script scripts/example.lisp sound-events
sbcl --script scripts/example.lisp mask-info
sbcl --script scripts/example.lisp display-info
```

From the REPL:

```lisp
(ql:quickload "pixelisp/examples")
(px.examples:list-examples) ; Fresh name/kind/description plists.
(px.examples:run-example :image-lab :frames 120)
(px.examples:run-example "star-collector" :audio nil)
(px.examples:run-example "pixels" :output #p"gradient.png")
(px.examples:audio-events-demo :timeout-ms 2000)
(px.examples:ui-lab :frames 120)
(px:with-resource (image (px.examples:pixel-match-demo :distance 0.2 :transposed t))
  (px.image:save image #p"pixel-match.png"))
```

`run-example` returns an owned surface for image examples when `:output` is
omitted. Wrap it in `px:with-resource` or dispose it after use. Supplying
`:output` saves and disposes the surface automatically. Interactive examples
own their runtime and release resources through `with-init`, including when
callbacks signal a condition. The sprite lab shares a particle image, the
mask lab updates its label only when overlap changes, and the image lab
precomputes its previews before entering the loop.

`make test-examples` runs bounded examples with dummy drivers, clicks the
sprite lab, switches image modes through queued key events, and verifies
cleanup. The same suite is available as `(asdf:test-system "pixelisp/examples")`.
The UI lab owns its runtime. Exiting clears queue filters and releases both
window grabs, including after callback errors.
The pixel lab enables keyboard repeat and caches its preview until a setting
changes. Its temporary pixel/transpose views close before any image is blitted.
Each edit starts from the original chart; repeated tolerance changes do not
accumulate replacements. Shutdown resets repeat settings.
